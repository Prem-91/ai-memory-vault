# AI Memory Vault

## Project Overview
AI Memory Vault is a comprehensive solution designed to securely store, manage, and retrieve memories using artificial intelligence. Leveraging various machine learning models, this tool aims to enhance memory recall and organization.

## Features
- **Secure Memory Storage**: Keep your memories safe with state-of-the-art encryption techniques.
- **AI-Powered Retrieval**: Easily retrieve memories using advanced AI algorithms.
- **User-Friendly Interface**: A simple and intuitive interface for seamless interaction.
- **Custom Categorization**: Organize memories into customizable categories.

## Technology Stack
- **Frontend**: React.js for building user interfaces.
- **Backend**: Node.js and Express for server-side logic.
- **Database**: MongoDB for data storage.
- **Authentication**: JWT for secure user authentication.
- **Machine Learning**: Python with TensorFlow for AI functionalities.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Prem-91/ai-memory-vault.git
   cd ai-memory-vault
   ```
2. Install front-end dependencies:
   ```bash
   cd frontend
   npm install
   ```
3. Install back-end dependencies:
   ```bash
   cd backend
   npm install
   ```
4. Set up your environment variables and database connection.
5. Start the application:
   ```bash
   # In the backend
   npm start
   # In another terminal, navigate to the frontend
   npm start
   ```

## Usage
1. Navigate to the application in your browser at `http://localhost:3000`.
2. Register or log in to your account.
3. Start adding and organizing memories.
4. Use the AI retrieval functionality to find specific memories easily.

## Architecture
The application follows a microservices architecture with separate components handling frontend and backend processes:
- **Frontend**: Handles user interactions and displays memories effectively through a responsive UI.
- **Backend**: Manages data requests, user authentication, and integrates with the database and AI models.
